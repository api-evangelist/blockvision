TL;DR; BlockVision is pleased to announce we launch its highly anticipated Indexing API today. This revolutionary API aims to provide developers and users with seamless access to valuable information about both NFT and coins on Sui Network, enabling them to retrieve specific details effortlessly. With the power of the Indexing API, users or developers can access information regarding account collections, individual collection details, top holders, NFT lists, and coin holders.
